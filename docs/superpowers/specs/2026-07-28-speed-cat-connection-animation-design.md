# 猫咪连接按钮动效设计

## 目标

添加并选中线路后，首页中央的 VPN 开关仍使用 ClashMiao 猫咪 Logo，不再显示通用电源、同步或盾牌图标。

点击连接时，黄色闪电与白色猫头分层运动：闪电先轻轻上抬、放大并亮一下，随后蓝色光圈从按钮中心向外扩散。连接成功后保留克制的蓝色呼吸光，让连接状态清晰但不喧宾夺主。

## 视觉状态

### 未连接

- 中央按钮使用现有靛蓝渐变圆形底盘。
- 白色猫头与黄色闪电居中显示。
- 保留轻微阴影，不显示动态光圈。
- 猫咪下方继续显示“点击连接”，维持现有操作提示。

### 正在连接

- 点击后的前 220ms，闪电向上移动约 8px，并从 1.0 放大到约 1.18。
- 闪电同时增加黄色高光与柔和辉光，形成短促的“通电”瞬间。
- 约 120ms 后，第一圈蓝色光环开始由内向外扩散并淡出；第二圈错开约 180ms 跟随。
- 闪电在约 420–600ms 内平稳回落到略微抬起的连接态位置。
- 动画不改变真实连接流程，按钮在 `BoxStarting` 期间继续禁止重复点击。

### 已连接

- 猫咪 Logo 保持完整可见，闪电维持轻微亮度提升。
- 按钮外围保留低强度蓝色呼吸光和间歇扩散光圈。
- 状态文案继续显示“已连接”。

### 正在断开与已断开

- 正在断开时，蓝色光晕收回并淡出，闪电恢复默认位置和大小。
- 已断开后回到静态猫咪 Logo。
- 不使用红色闪烁，避免与品牌主色冲突，也避免把正常断开表达为错误。

## 图形分层

现有 `brand_mark.png` 是猫头与闪电合成图，无法单独移动闪电。品牌资源生成脚本将额外输出两个透明图层：

- `assets/images/brand_cat.png`：仅白色猫头。
- `assets/images/brand_bolt.png`：仅黄色闪电。

两个图层从同一个品牌源图按颜色蒙版生成，因此形状、位置和现有 Logo 完全一致。现有应用图标、托盘图标和 `BrandMark` 保持不变。

## 组件结构

新增独立的 `SpeedCatConnectionMark` 组件，负责：

- 叠放猫头和闪电图层。
- 根据 `BoxStopped`、`BoxStarting`、`BoxStarted`、`BoxStopping` 驱动动画。
- 绘制蓝色光晕与扩散光圈。
- 在系统关闭动画时直接切换最终状态。

`ConnectionButton` 继续负责点击、实验性功能确认和状态文案，只把目前的通用图标区域替换为 `SpeedCatConnectionMark`。连接控制器和 VPN 启停逻辑不作修改。

## 动效约束

- 主动画约 600ms，使用快速起势、柔和回落的曲线。
- 光圈只使用品牌蓝与靛蓝，不新增第三套强调色。
- 动画图层放在 `RepaintBoundary` 内，避免首页其它区域重复重绘。
- 尊重系统“减少动态效果”设置；关闭动画时仍显示正确的静态连接状态。
- 所有状态变化由真实 `BoxStatus` 驱动，不能用延时假装连接成功。

## 测试与验收

- 资源测试验证猫头层只包含白色主体、闪电层只包含黄色主体，并保持透明背景与现有几何位置。
- 组件测试验证四种连接状态都显示猫咪 Logo，不再出现电源、同步或盾牌图标。
- 动效测试验证进入 `BoxStarting` 后闪电图层发生独立位移和缩放，蓝色光圈出现；进入 `BoxStarted` 后保留连接光晕。
- 点击与状态锁测试继续验证未连接和已连接时可点击、切换期间不可重复点击。
- 完整运行静态分析、单元测试、macOS 构建和签名检查。
- 重启本地应用后检查未连接与已添加线路页面，确认中央按钮始终为猫咪 Logo。
